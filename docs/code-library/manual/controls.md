# Controls

| Key | Action |
| --- | --- |
| Tab / Shift+Tab | Move between controls |
| Enter / Space | Activate a focused control |
| Arrow keys | Move across channels when the map has focus; switch views inside the open view menu |
| N | Select highest burnup |
| R | Add / remove selected channel |
| F1 | Open manual |
| Escape | Close manual |

## Saves & starting cores

Menu → Manual opens this guide. Saves · Stats · Login opens local saves, optional GitHub login, private cloud saves and the endless leaderboard. Guest/offline play is available. Daily saves include the unfinished fuel plan. Older real-time saves cannot resume in the public daily game.

The same seed recreates the same aged core. New shift draws a new seed; retry preserves the current seed and objective. A new run clears history, reports and badges.

The loaded build and physics version are shown in the update strip. Save locally & update preserves a local save before loading an available update. Close other game tabs first; keep browser site data to retain local saves.
