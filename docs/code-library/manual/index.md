# Player manual

CRS is an on-power refuelling game played one simulated day at a time. The player
inspects a frozen reactor, drafts fuel movements, advances a day, and reads the
result. These chapters explain the controls and the measurements needed to make
that decision.

| Chapter | Subject |
| --- | --- |
| [Quick start](start.md) | The daily loop and endless free practice |
| [Fuelling](fuel.md) | Eight-bundle moves, flow direction, outgoing fuel and plan order |
| [Reactor theory](physics.md) | A concise explanation of the physical readings |
| [Maps and readings](maps.md) | Map modes, channel profiles, device geometry and history |
| [Limits and score](score.md) | Operating limits, ripple points and ending reports |
| [Controls and saves](controls.md) | Keyboard operation, seeds, local saves and updates |
| [Simulation model](model.md) | What a daily calculation includes and its scope |

The same Markdown chapters supply the game's **Menu → Manual** / **F1** dialog.
They are bundled with the game, so the in-game manual remains available offline.
The website adds searchable navigation and links to the more detailed
[reactor theory](../theory/index.md) and [code walkthrough](../index.md).
