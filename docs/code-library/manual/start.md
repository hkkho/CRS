# One day at a time

1. Read the core’s LZC average, tilt and power peaks.
2. Select a channel on the core map, or use **Highest burnup**. Compare its power and burnup profiles at both ends.
3. Select **Add channel** to draft an eight-bundle move. Inspect the outgoing fuel strip. Add more channels if needed.
4. Open **Fuel plan** to review the orders, then select **Refuel & advance**. With an empty plan, **Advance day** advances without fuel.
5. Read the day result and repeat. Time stays frozen while you inspect, plan or read this manual.

Free practice has unlimited fresh fuel and no time limit. The one-day challenge has finite fuel: discharge at least eight bundles at 6 MWd/kg HM or above and finish within the operating limits to earn Efficient refueller.

Highest burnup ranks eligible channels by observed average burnup. It is a candidate list, not a prediction of the best move. Compare outgoing bundles, channel power and zone headroom before choosing.
