# Reactor theory

CRS uses an authored two-group spatial approximation to calculate reactor state. Read about the [solver and half-day approximation](numerical-model.md), [fuel and burnup](fuel.md), and [poison and regulation](regulation.md). These pages describe the game model, not a plant operations model.

The [geometry fit](../../../data/calibration/diffusion-v10/README.md) and [xenon calibration](../../physics/xenon-calibration.md) record the authored parameters and validation experiments. The [player manual](../manual/index.md) connects these concepts to the map, controls and limits.
