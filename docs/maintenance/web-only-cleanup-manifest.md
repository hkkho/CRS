# Web-only repository scope

The sole developed game is `web/candu-playtest` and its authoritative
Core/Game/Browser/BrowserHost simulation, deployed through GitHub Pages.

The October 10, 2026 cleanup retired 229 obsolete tracked files (about 6.45 MB):

- Separate Core.Research engine, complete legacy transitions, device queues,
  reduced-model authorities and their duplicate tests.
- GPU shaders, fixture exports, host modules and experimental bridge tests.
- Alternate browser-thread host and superseded single-solve campaign proposal.
- DRAGON/DONJON execution/export pipelines and historical admission schemas.
- Unused phase-era golden/comparison data and project benchmarks.
- Superseded task ledgers, build inventories, specs and experiment guides.

Retained material serves the web product or its physics: current tests and wire
fixtures, shared adjoint/diffusion metadata, native numerical tools, authored packs,
calibration source chains, equations, source literature and useful raw measurements.
Historical physics reports are labelled as comparisons, not current acceptance
values. The knowledge library and contributor guide now point to the active path.
Publishing has one single-threaded WASM host. Optional profiling instruments that
same solver. Daily gameplay, save/replay, display scales and deterministic solver
reproduction protect releases.

Only reviewed tracked files were deleted; untracked files were preserved. Git
history retains committed sources. Exact pre-cleanup working bytes were checked
against local recovery archives in `tmp/web-only-cleanup/retired-sources.zip` and
`tmp/web-only-cleanup/remaining-retired-source.zip` before removal. These ignored
archives also retain pending edits to retired files.

Generated build trees and local study uploads remain ignored. Do not introduce
another game client, runtime solver dependency or phase-era work plan. Keep new
knowledge near the physics/calibration it explains and new production behavior in
the existing web/shared layers.
