## Assumptions and design choices

- Applicable P1-T08 literature rows are `S1-R07`, `S4-R03`, `S4-R04`, `S5-R05`,
  and `S6-R05`. They were used as background, methodology, or candidate-case
  context only. The approved P2-T03/P2-T04/P2-T05 specifications remain the
  runtime authorities; no literature number, coefficient, tolerance, or golden
  value was admitted.
- The explicit I/Xe equations, SI units, left-endpoint time rule, version
  progression, history continuity, and fail-closed invalid-state behavior are
  taken from the approved specifications. The test fixture values are
  synthetic contract checks, not reference data.
- Complete canonical bytes are deterministic in-memory digest projections,
  not JSON or Unity serialization formats. They bind all state needed for the
  complete Core transition boundary without creating a runtime DONJON5/DRAGON5
  dependency.
- The legacy basic `BundleState` constructor remains available for existing
  bounded fixtures. Complete Phase 5 transitions fail closed when a required
  I/Xe envelope or lifecycle version binding is absent.
- Prepared refuelling is additive: the existing immediate API captures and
  applies a request at one lifecycle boundary, while callers that prepare a
  shift for later commit must use the prepared-request overload.
