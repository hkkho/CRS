## Assumptions and design choices

- The plan names the template types but not all filenames. The conventional locations `docs/tasks/TASK_REPORT_TEMPLATE.md`, `docs/adr/ADR_TEMPLATE.md`, and `docs/gates/GATE_REPORT_TEMPLATE.md` were selected within the already-planned directories.
- `CODEX_TASK_TEMPLATE.md` represents the task input contract, while `TASK_REPORT_TEMPLATE.md` represents the evidence produced after execution; keeping them separate matches sections 6 and 10 of the plan.
- `AGENTS.md` applies repository-wide and summarizes enforceable rules from the plan without selecting equations, packages, versions, tolerances, or implementation mechanisms.
- Local links use the existing on-disk filename `docs/Implementation_plan.md` and its correct relative path from each template.
- The templates retain explicit placeholders rather than inventing project decisions or evidence.

### Required structure, local links, code fences, and whitespace - T0 documentation check

```powershell
$requiredFiles = @(
    'AGENTS.md',
    'CODEX_TASK_TEMPLATE.md',
    'docs/tasks/TASK_REPORT_TEMPLATE.md',
    'docs/adr/ADR_TEMPLATE.md',
    'docs/gates/GATE_REPORT_TEMPLATE.md'
)
$missingFiles = @($requiredFiles | Where-Object {
    -not (Test-Path -LiteralPath $_ -PathType Leaf)
})
if ($missingFiles) {
    Write-Error ('Missing files: ' + ($missingFiles -join ', '))
    exit 1
}

$requiredText = @{
    'AGENTS.md' = @(
        '## Required reading and task scope',
        '## Architecture boundaries',
        '## Proportionate validation',
        '## Required task report',
        '## Stop conditions'
    )
    'CODEX_TASK_TEMPLATE.md' = @(
        'Task ID:', 'Model / reasoning:', 'Objective:',
        'Allowed files/subsystems:', 'Inputs and approved specifications:',
        'Required behavior and invariants:', 'Explicit non-goals:',
        'Focused checks to run:', 'Full-suite instruction:',
        'Required report path:', 'Definition of done:'
    )
    'docs/tasks/TASK_REPORT_TEMPLATE.md' = @(
        '## Outcome', '## Files created or changed',
        '## Assumptions and design choices',
        '## Validation commands and results', '## Numerical differences',
        '## Deferred validation', '## Blockers, risks, and follow-up',
        '## Next eligible task'
    )
    'docs/adr/ADR_TEMPLATE.md' = @(
        '## Context', '## Decision',
        '## Architectural boundaries and invariants', '## Consequences',
        '## Alternatives considered', '## Validation and evidence',
        '## Follow-up', '## References'
    )
    'docs/gates/GATE_REPORT_TEMPLATE.md' = @(
        '## Result', '## Scope reviewed', '## Evidence and commands',
        '## Findings', '## Numerical comparison summary',
        '## Required corrective tasks', '## Risks accepted or deferred',
        '## Next bounded tasks', '## Review sign-off'
    )
}
$missingText = @()
foreach ($path in $requiredText.Keys) {
    $content = Get-Content -Raw -LiteralPath $path
    foreach ($textValue in $requiredText[$path]) {
        if (-not $content.Contains($textValue)) {
            $missingText += ($path + ' :: ' + $textValue)
        }
    }
}
if ($missingText) {
    Write-Error ('Missing required text: ' + ($missingText -join '; '))
    exit 1
}

$brokenLinks = @()
$unbalancedFences = @()
foreach ($path in $requiredFiles) {
    $item = Get-Item -LiteralPath $path
    $content = Get-Content -Raw -LiteralPath $path
    foreach ($match in [regex]::Matches($content, '\[[^\]]+\]\(([^)]+)\)')) {
        $target = $match.Groups[1].Value
        if ($target -match '^[a-z]+://' -or $target.StartsWith('#')) {
            continue
        }
        $targetPath = $target.Split('#')[0]
        $resolved = [System.IO.Path]::GetFullPath(
            (Join-Path $item.DirectoryName $targetPath)
        )
        if (-not (Test-Path -LiteralPath $resolved)) {
            $brokenLinks += ($path + ' -> ' + $target)
        }
    }
    $fenceCount = [regex]::Matches($content, '(?m)^```').Count
    if (($fenceCount % 2) -ne 0) {
        $unbalancedFences += ($path + ' (' + $fenceCount + ')')
    }
}
if ($brokenLinks) {
    Write-Error ('Broken local links: ' + ($brokenLinks -join '; '))
    exit 1
}
if ($unbalancedFences) {
    Write-Error ('Unbalanced code fences: ' + ($unbalancedFences -join '; '))
    exit 1
}

rg -n '[ \t]+$' AGENTS.md CODEX_TASK_TEMPLATE.md `
    docs/tasks/TASK_REPORT_TEMPLATE.md docs/adr/ADR_TEMPLATE.md `
    docs/gates/GATE_REPORT_TEMPLATE.md
if ($LASTEXITCODE -eq 0) {
    exit 1
} elseif ($LASTEXITCODE -ne 1) {
    exit $LASTEXITCODE
}
```

Result: exit code 0. All 5 required files and all required sections were present. Every local Markdown link resolved, every fenced block was balanced, and no trailing whitespace was found.
