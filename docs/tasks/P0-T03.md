## Assumptions and design choices

- SDK `10.0.302` is the only installed SDK and was pinned exactly for reproducible development. Environments without that exact SDK will fail closed instead of silently rolling to another compiler.
- CLI and tests target .NET 10. Core overrides the shared target with `netstandard2.1`, matching the later Unity 6 compatibility boundary while remaining consumable by the headless .NET 10 projects.
- Core disables implicit usings because its `netstandard2.1` default language level is C# 8 and generated global usings require C# 10. The language version was not raised speculatively.
- The final test baseline uses `Microsoft.NET.Test.Sdk` `18.8.1`, `xunit.v3` `3.2.2`, and `xunit.runner.visualstudio` `3.1.5`. These were the maintained stable versions identified through official xUnit and NuGet sources on 2026-08-06. Runner assets are private.
- The optional `coverlet.collector` package from the SDK's bundled legacy xUnit template was omitted because coverage is not required for P0-T03.
- Both test projects receive the test framework now so their dependency direction and runner configuration are established consistently. Only Core.Tests contains the one required trivial test.
- `Assert.True(true)` intentionally validates only discovery/execution. Adding a production marker type solely for the test would be speculative Core API surface.
- Serialization-library selection is not part of the bounded P0-T03 queue item and remains unresolved before G0.
