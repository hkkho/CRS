## Assumptions and design choices

- The admitted comparison boundary is the synthetic/reduced model selected by
  R2D. Direct Candu6.x2m source admission remains retired and is not silently
  substituted for the candidate.
- The comparison tool reuses the existing `BurnupCoefficientTableV1` and
  `SpatialRecomputeRequestV1` contracts. It adds no runtime dependency and
  serializes no new public runtime schema.
- R4 source, pack, and manifest bytes are bound by their existing SHA-256
  identities and per-table metadata. Benchmark metadata is bound to the
  existing P4-T08 fixture values rather than treated as presence-only.
- P2-T05 opaque IDs use canonical `Bytes` encoding, typed scope keys use the
  closed field layouts, vector ordering carries the complete approved profile,
  and negative zero/non-finite canonical values fail closed.
- The inherited P4-T08 maximum outer iteration count of 2 is preserved. R5
  does not loosen convergence or convert the refuelled failure into a usable
  snapshot.
- Provenance is a path-free stable label. Host paths, URLs, traversal tokens,
  and similar host-local values are rejected before comparison evidence is
  admitted.
