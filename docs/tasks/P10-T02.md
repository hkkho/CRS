## Assumptions and design choices

- The shell uses a 1920x1080 landscape reference resolution with
  `MatchWidthOrHeight` at `0.5`; this is a presentation layout choice, not a
  simulation time or physics rule.
- `Screen.safeArea` is mapped to normalized anchors on a dedicated content
  root, with offsets reset to zero. A zero/invalid screen size is ignored by
  the runtime refresh and rejected by the explicit test helper.
- Dashboard, Core Map, Timeline, and Controls are placeholders. No snapshot,
  command, parameter-pack, save/replay, clock, or Core/CLI data was added.
- Navigation is deterministic and emits `PageChanged` only on an actual page
  transition. Each button has a minimum/preferred height of 88 reference
  pixels as the approved visual touch-size baseline.
- The shell has no `Update` callback and uses no Unity time API. It builds an
  EventSystem only when playing and none exists; it does not advance or own
  simulation state.
- The built-in UGUI package was added because CanvasScaler, GraphicRaycaster,
  Button, Text, and layout components are explicitly required by this task;
  no third-party/native dependency was introduced.
- Literature applicability: `NotApplicable`; no physics equation, constant,
  unit, normalization, tolerance, reference case, or golden value was
  selected or changed.
