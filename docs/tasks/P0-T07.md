# P0-T07 - Fail closed headless test wrappers

## Outcome

Status: COMPLETE

P0-T07 hardens the focused and full headless test wrappers against VSTest's
zero-test exit-code success behavior. Each invocation now creates a fresh,
GUID-named external TRX directory, consumes every produced TRX file through
literal paths, and fails closed when the required machine-readable evidence is
missing or malformed. The focused wrapper preserves its exact FQN grammar and
requires exactly one passed result for the requested FQN. The full wrapper
retains `-ConfirmFullSuite` and requires at least one test execution across the
entire solution, while allowing the intentionally empty Golden project.

## Files created or changed

- `tools/Test-Focused.ps1` - emits fresh external TRX results and validates one
  exact passed test result plus complete nonzero counters.
- `tools/Test-FullHeadlessSuite.ps1` - emits fresh external TRX results and
  validates a nonzero aggregate executed-test count after the confirmation gate.
- `docs/tasks/P0-T07.md` - this task report.

The existing test projects, test source, production source, solution, toolchain
pins, Unity files, and all pre-existing reports were inspected but not changed.

## Assumptions and design choices

- Each wrapper creates a GUID-named directory beneath
  `[System.IO.Path]::GetTempPath()` for TRX output. This is independent of the
  caller-provided artifact path, starts empty, and remains external to the
  repository for diagnostics.
- Every discovered TRX is parsed with `Get-Content -Raw -LiteralPath`; missing,
  malformed, or incomplete counters throw rather than being treated as success.
  Literal paths are necessary because VSTest can create filenames containing
  brackets, such as `net10.0[1].trx`.
- The focused FQN expression is unchanged:
  ``^[A-Za-z_][A-Za-z0-9_.+`]*$``. Its TRX aggregate must be total/executed/passed
  equal to 1 with no non-success counters, and its sole `UnitTestResult` must
  name the requested FQN with outcome `Passed`.
- The full wrapper aggregates `executed` across all TRX files. A zero-test
  project is valid by itself; only a solution aggregate of zero throws.
- The isolated zero-test proof created an external source copy that omitted all
  `tests/**/*.cs` files during copying and then asserted none remained. This
  provides the requested all-test-source-removed condition without touching the
  working tree.

### Isolated all-test-source-removed full-suite rejection - T3 negative

```powershell
$sourceRoot = (Resolve-Path -LiteralPath '.').Path
$validationRoot = Join-Path ([System.IO.Path]::GetTempPath()) `
    ('candu-p0-t07-zero-test-source-' + [Guid]::NewGuid().ToString('N'))
$snapshotRoot = Join-Path $validationRoot 'source'
New-Item -ItemType Directory -Path $snapshotRoot -ErrorAction Stop | Out-Null

$status = @(git status --porcelain=v1 --untracked-files=all)
if ($status | Where-Object { -not $_.StartsWith('?? ') }) {
    throw 'The isolated-copy check requires no modified or deleted Git-visible paths.'
}

$omittedTestSource = @()
foreach ($line in $status) {
    $relative = $line.Substring(3)
    $relativeNative = $relative -replace '/', '\\'
    $sourcePath = Join-Path $sourceRoot $relativeNative
    if (-not (Test-Path -LiteralPath $sourcePath -PathType Leaf)) {
        throw "Git-visible path is not a file: $relative"
    }

    if ($relativeNative.StartsWith('tests\\',
            [System.StringComparison]::OrdinalIgnoreCase) -and
        [System.IO.Path]::GetExtension($relativeNative) -ieq '.cs') {
        $omittedTestSource += $relativeNative
        continue
    }

    $destination = Join-Path $snapshotRoot $relativeNative
    New-Item -ItemType Directory -Force -Path `
        (Split-Path -Parent $destination) | Out-Null
    Copy-Item -LiteralPath $sourcePath -Destination $destination -ErrorAction Stop
}

if ($omittedTestSource.Count -eq 0) {
    throw 'The source state contained no test source files to omit.'
}

$snapshotTestsRoot = Join-Path $snapshotRoot 'tests'
$remainingTestSource = @(Get-ChildItem -LiteralPath $snapshotTestsRoot `
        -Recurse -File -Filter '*.cs' -ErrorAction Stop)
if ($remainingTestSource.Count -ne 0) {
    throw "The isolated source copy still contains $($remainingTestSource.Count) test source file(s)."
}

$sourcePrefix = [System.IO.Path]::GetFullPath($sourceRoot).TrimEnd(
    [System.IO.Path]::DirectorySeparatorChar) + [System.IO.Path]::DirectorySeparatorChar
$snapshotPrefix = [System.IO.Path]::GetFullPath($snapshotRoot).TrimEnd(
    [System.IO.Path]::DirectorySeparatorChar) + [System.IO.Path]::DirectorySeparatorChar
if ($snapshotPrefix.StartsWith($sourcePrefix,
        [System.StringComparison]::OrdinalIgnoreCase)) {
    throw 'The isolated-copy path must remain outside the working tree.'
}

try {
    & (Join-Path $snapshotRoot 'tools\Test-FullHeadlessSuite.ps1') `
        -ConfirmFullSuite `
        -ArtifactsPath (Join-Path $validationRoot 'artifacts')
    throw 'The full-suite wrapper unexpectedly accepted an isolated solution with zero test source files.'
}
catch {
    if ($_.Exception.Message -notlike
        'The full headless suite executed zero tests according to TRX results*') {
        throw
    }
    Write-Output "PASS: isolated zero-test solution was rejected: $($_.Exception.Message)"
}

Write-Output "Omitted $($omittedTestSource.Count) test source file(s) only while creating isolated copy: $($omittedTestSource -join ', ')"
Write-Output "Validation root retained: $validationRoot"
```

Result: exit code 0 for the validation harness. The external copy omitted
`tests\ReactorSim.Core.Tests\TestHarnessTests.cs` and contained no remaining
test `.cs` file. Its full test invocation produced two zero-test TRXs, including
`infin_RYZENHO_2026-08-07_01_47_46_net10.0[1].trx`; both had
`total=0`, `executed=0`, `passed=0`, and `failed=0`. The wrapper read both
literal paths and threw `The full headless suite executed zero tests...`, which
the harness accepted as the required failure.

### Final scope inspection - T0

```powershell
$repositoryRoot = (Resolve-Path -LiteralPath '.').Path
$baselineRoot = 'C:\Users\infin\AppData\Local\Temp\candu-p0-t07-baseline-20260807'
$allowedChanged = @(
    'tools/Test-Focused.ps1',
    'tools/Test-FullHeadlessSuite.ps1'
)
$expectedNew = 'docs/tasks/P0-T07.md'

$status = @(git status --porcelain=v1 --untracked-files=all)
if ($status | Where-Object { -not $_.StartsWith('?? ') }) {
    throw "Unexpected Git status: $($status -join '; ')"
}

$baselineFiles = @(Get-ChildItem -LiteralPath $baselineRoot -Recurse -File |
        ForEach-Object {
            ($_.FullName.Substring($baselineRoot.Length).TrimStart(
                [char[]]@('\', '/')) -replace '\\', '/')
        } |
        Sort-Object)
if ($baselineFiles.Count -ne 85) {
    throw "Expected 85 baseline files, found $($baselineFiles.Count)."
}

$changedBaseline = @()
foreach ($relative in $baselineFiles) {
    $currentPath = Join-Path $repositoryRoot $relative
    $baselinePath = Join-Path $baselineRoot $relative
    if (-not (Test-Path -LiteralPath $currentPath -PathType Leaf)) {
        throw "Baseline file is missing from the working tree: $relative"
    }

    if ((Get-FileHash -Algorithm SHA256 -LiteralPath $currentPath).Hash -ne
        (Get-FileHash -Algorithm SHA256 -LiteralPath $baselinePath).Hash) {
        $changedBaseline += $relative
    }
}

$unexpectedChanged = @($changedBaseline | Where-Object {
        $_ -notin $allowedChanged
    })
if ($unexpectedChanged) {
    throw "Pre-existing file changed outside P0-T07 scope: $($unexpectedChanged -join ', ')"
}
if (Compare-Object ($allowedChanged | Sort-Object) ($changedBaseline | Sort-Object)) {
    throw "Expected changed baseline paths '$($allowedChanged -join ', ')', found '$($changedBaseline -join ', ')'."
}

$currentPaths = @($status | ForEach-Object {
        ($_.Substring(3) -replace '\\', '/')
    } | Sort-Object)
$unexpectedPaths = @($currentPaths | Where-Object {
        $_ -notin $allowedChanged -and $_ -ne $expectedNew -and
        $_ -notin $baselineFiles
    })
if ($unexpectedPaths) {
    throw "Unexpected path(s): $($unexpectedPaths -join ', ')"
}
if ($currentPaths -notcontains $expectedNew) {
    throw "Missing task report: $expectedNew"
}
Write-Output "PASS: 85 baseline files checked; changed baseline files: $($changedBaseline -join ', '); new task report: $expectedNew"
```

Result: exit code 0. All 85 baseline files were present and hash-compared; only
`tools/Test-Focused.ps1` and `tools/Test-FullHeadlessSuite.ps1` differed. The
sole new Git-visible path was `docs/tasks/P0-T07.md`.
