# P5-T08 - Deterministic multistep refuelling histories

## Outcome

Status: COMPLETE

P5-T08 adds bounded deterministic history evidence as a test-only harness over
the already approved immutable Core transitions. It runs repeated explicit
10-second burnup intervals followed by equal-time atomic S4 or S8 refuelling
shifts, advances the synthetic core version once per accepted interval and
once per accepted refuelling batch, checks exact invariant reports at every
step, verifies that fresh identities are never reused, and compares replay
fingerprints under reversed accepted-power input order. The fingerprint
includes every canonical burnup record field, every ordered discharged state,
and the resulting live inventory state.

This task intentionally does not add a runtime history schema, I/Xe/lifecycle
envelope, canonical production digest serializer, DONJON5 comparison, or
golden baseline. Those boundaries require their approved owners and the
unresolved P4-T06 reference-admission evidence.

Effectiveness: SUCCESS

## Assumptions and design choices

- The Phase 5 work-package-8 evidence boundary is test-only because no
  approved public multistep history schema exists. The harness composes the
  existing `BurnupIntervalTransition`, `RefuelShiftTransition`, and
  `Phase5InvariantValidatorV1` contracts and does not create a competing
  runtime owner.
- Each synthetic interval uses the approved left-endpoint rule and is split
  at the equal-time refuelling event. A newly inserted bundle receives no
  energy in the preceding interval and participates in the next interval only.
- Synthetic histories cover 32 repeated S4 cycles in `EndAtoEndB` flow and 24
  repeated S8 cycles in `EndBtoEndA` flow. These are deterministic test
  scenarios, not production operating limits, reference values, or golden
  baselines.
- The harness computes a test-only SHA-256 fingerprint over explicitly ordered
  current `BundleState` fields. It is a repeatability witness, not a canonical
  runtime serializer or an approved state-digest algorithm.
- The applicable P1-T08 rows are `S1-R07`, `S4-R03`, `S4-R04`, `S5-R05`, and
  `S6-R05`. They are background/methodology or candidate-case-design context
  only; `S4-R04` is advanced-fuel context outside this runtime slice. No
  literature number, coefficient, tolerance, checksum, or golden value was
  admitted.
- `G2` remains exactly `FORCED CLOSED / WAIVED`. The synthetic history work is
  independent of the blocked P4-T06 DONJON5 licensing/data and solver-mapping
  admission. Reference comparison and G5 evidence remain deferred.
