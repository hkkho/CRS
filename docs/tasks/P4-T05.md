- The one-node/no-leakage case follows the exact P2-T02 worked-example values
  and is tested as algebra because P2-T02 explicitly classifies that section
  as algebraic contract checks. No runtime topology boundary was changed.
- Runtime synthetic cases use two or three positions, reflective boundaries,
  explicit reciprocal within-channel edges, equal coefficients where the
  symmetry/homogeneity contract requires them, and caller-supplied target power.
- The deliberate nonconvergence policy uses P2-T02's explicit synthetic
  `maximum_iterations=1`, k tolerances `0.01`, and other tolerances `0.000001`.
  Other positive tolerances in successful test fixtures are test inputs only;
  none is an approved production threshold.
- Reordered node, edge, and boundary records are supplied to the same
  topology-bound coefficient contract; the assertions compare status,
  diagnostics, and final flux arrays rather than reference values.
- Applicable P1-T08 digest rows were `S1-R03`, `S1-R04`, `S1-R05`, `S1-R06`,

  background/context only. No literature numeric result, reference case,
  tolerance, equation authority, or golden value was selected.

  contracts and does not treat the waiver as technical approval.
