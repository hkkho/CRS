## Independence and authority requirements

The task must satisfy every requirement below. A missing requirement is a
blocking result, not a reason to downgrade the claim:

- Expected values must be produced by a separately implemented or exactly
  constructed oracle that does not reference `ReactorSim.Core`, the G4J
  `Program.cs`, the G4J serialized expected results, or Core's numerical
  solver implementation.
- The reference method must be materially independent from the Core/G4J
  Jacobi path. Its equations and sign/normalization mapping remain the frozen
  P2 contracts; the task must document the independent algorithm or exact
  construction and have it reviewed.
- The reference case input must be independently serialized and hash-bound.
  Reusing semantic G4J inputs is allowed only when the independent manifest
  records the exact reuse and the expected outputs are regenerated by the
  independent authority rather than copied from G4J.
- The authority must bind exact source program/model/tool/version/build and an
  immutable source snapshot. If the workspace has no Git HEAD, record
  `UNAVAILABLE_NO_GIT_HEAD` and bind a complete content-addressed source
  manifest; do not claim release or external authority from a local hash alone.
- Material/nuclear identity, geometry/topology/mesh, state/history/event order,
  units/conversions, normalization/sign, observable/schema/order/comparison,
  reproduction/convergence/statistics, and redistribution rights must all be
  explicit. `NotReported` or an unresolved mapping blocks admission.
- An external source may be used only with exact tool/build, nuclear-data
  identity, input/output case identity, rights, and reproducible regeneration.
  Stop on inaccessible artifacts, unclear licensing, missing nuclear data, or
  source/model/unit/normalization mismatch.
- The reference process must freeze expected outputs before the Core consumer
  reads them. A test that regenerates both sides from the same implementation
  is not evidence of independence.
