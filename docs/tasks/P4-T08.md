## Assumptions and design choices

- The benchmark reuses the P4-T05 homogeneous three-node case and its
  caller-supplied synthetic policy values. These values are test inputs, not
  approved performance or numerical thresholds.
- Topology/coefficient/solver setup and manifest validation occur before the
  timed interval. Each measured operation calls the existing public Core solve
  and requires `Converged` plus `HasUsableState`.
- Exact equality of final eigenvalue, final flux arrays, final power, and
  iteration count across measured repeats is a determinism check. It is not a
  reference comparison.
- `Stopwatch` and `GC.GetAllocatedBytesForCurrentThread` report a local desktop
  observation. The task establishes no latency, allocation, mobile, thermal,
  or release budget; optimization remains deferred until the plan's later
  performance phase.
- P1-T08 literature rows are `NotApplicable`: this benchmark consumes only
  frozen P2-T01/P2-T02 contracts and committed synthetic P4-T05 inputs; it
  uses no literature number, external reference, nuclear data, or golden case.
- P4-T06 remains blocked by external reference admission. The benchmark is
  eligible under the gate-overlap policy because it does not depend on the
  unresolved reference finding.
