## Assumptions and design choices

- P2-T04 remains the runtime authority for the Xe production/loss equations,
  SI units, absorption-only overlay, xenon-free base requirement, event order,
  and mandatory post-Xe spatial solve. The implementation does not select
  values from literature or infer a reference case.
- `SpatialCoefficientSet.TryCreate` now produces an explicit
  `XenonBasis=Unspecified` identity unless its caller uses the additive
  `TryCreateWithXenonBasis` boundary. Dynamic coupling accepts only a validated
  `Excluded` marker with exact canonical `ReferenceXeNumberDensityM3=0`.
- The base coefficient digest is computed over the marker/reference, exact
  stencil terms, node coefficients, reciprocal edge conductances, and boundary
  conductances. The supplied digest must equal that identity before overlay.
- For each node, the only new coefficient is
  `Sigma_Xe,g = sigma_Xe,g * N_Xe` in `m^-1`; fission, scattering, chi, volume,
  and energy-per-fission remain unchanged. Rebinding runs the complete existing
  P2-T02 coefficient validation, including `Sigma_a >= Sigma_f` and group
  invariants.
- The caller supplies `XenonSpatialStateBindingV1`; it carries exact simulation
  time, kinetic amplitude, `CoreStateVersion`, state/topology/data-pack digests,
  and every node `NuclideStateVersion`. The coupling and accepted solve retain
  this tuple and reject stale positive-duration advancement.
- `XenonSpatialSolveV1` composes the existing P2-T02 iteration/outer solve with
  `SpatialRecomputeCadenceV1`. It does not choose cadence periods, convergence
  thresholds, normalization targets, or lifecycle versions. A nonconverged solve
  returns an invalid result before cadence advancement.
- Applicable P1-T08 literature rows are `S1-R09` (135Xe methodology/context
  only), `S4-R05` (refuelling/reactivity/device context only), `S4-R06`
  (blocked candidate comparison evidence with no approved baseline), and
  `S5-R08` (candidate case-design context with no runtime mapping). They provide
  no runtime equation, coefficient, tolerance, or golden authority; P2-T04
  remains authoritative.
