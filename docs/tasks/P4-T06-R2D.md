# P4-T06-R2D - Reduced/synthetic model admission disposition

## Outcome

Status: COMPLETE

P4-T06-R2D records the owner-approved technical disposition for the unresolved
Candu6.x2m source-to-P2-T02 admission gap. The selected disposition is Option 3
from the authorized follow-up chain:

> Direct Candu6.x2m admission as a source of P2-T02 coefficients, node
> identity, volumes, per-fission energy, topology, normalization, or golden
> comparison values is not admitted. The affected reference path continues
> only through a separately specified reduced/synthetic offline model and its
> compact interpolation-data boundary.

This decision is based on the owner's current direction that redistribution
rights are available and that the final game will use a simplified model with
offline-generated interpolation data rather than the exact reference data.
It resolves the technical admission choice without pretending that the
missing source mapping exists.

The following boundaries are now authoritative for the next task chain:

1. DONJON5/DRAGON5 remain offline tools only. No executable, raw case payload,
   exact Candu6.x2m output, or direct DONJON5 runtime dependency is admitted to
   the game.
2. The P2-T01 topology/indexing contract, P2-T02 two-group coefficient,
   normalization, and convergence contract, P2-T03 burnup/I-Xe/refuelling
   contract, and P2-T05 observable/reference-evidence contract are unchanged.
   This decision does not select a replacement equation, unit, sign,
   normalization, convergence rule, tolerance, public schema, or golden value.
3. The reduced/synthetic path is a separate offline model boundary. `P4-T06-R3`
   must freeze its allowed transformations, valid domain, provenance, compact
   interpolation-data fields, and runtime/non-runtime separation before
   `P4-T06-R4` creates any data pack or converter output.
4. Any later use of external reference output as candidate training or
   calibration evidence must be explicitly described and traceable in R3/R4.
   It remains candidate evidence until R5 and the appropriate gate approve the
   comparison domain; it is not a direct P2-T02 field authority.
5. G4 retains ownership of spatial comparison quantities and tolerances. G5
   retains ownership of refuelling/depletion comparison quantities and
   tolerances. No threshold is created by this decision.

The historical `P4-T06`, `P4-T06-R2`, `P4-T06-R2A`, `P4-T06-R2B`, and
`P4-T06-R2C` reports remain unchanged. R2C remains historical `BLOCKED`
evidence for direct source admission; R2D is the complete administrative and
technical disposition that selects the alternate boundary. No runtime or
reference-data implementation was performed in this decision task.

Effectiveness: SUCCESS
