## Assumptions and design choices

- The parser accepts only the canonical repository P1-T03 descriptor at SHA-256 `09851b1ee3155592eaa379454f2baa615af3749f82507bbb4ad526f0282a881b` and its fixed Version5/tool identity.
- Required source order is the observed P1-T03 runtime order: two exact SPHAPX warnings, final FLDDIR row, multiplication factor, MAXOUT, KEFF and FLUX EPSOUT records, runtime assertion, runtime completion, and normal end.
- The echoed input completion does not satisfy the anchored `>|...|>line` runtime record. Duplicate, malformed, reordered, missing, non-finite, fatal, nonconverged, or unexpected-warning evidence fails closed.
- `DELT <= EPSOUT` is checked from emitted source evidence. The parser does not invent or relax a tolerance.
- Compact numbers preserve exact decimal agreement with their source lexemes. Output uses strict UTF-8 without BOM, LF, two-space indentation, fixed insertion/array order, and one terminal LF.
- Output is created exclusively outside the repository. Existing targets, traversal/reparse escapes into the repository, ADS-like names, and Windows device basenames (including multi-extension names) are rejected.
- The retained raw listing remains external/private. Publication, vendoring, mirroring, or redistribution remains a legal/export-control stop condition.
