## Assumptions and design choices

- The P9-T03 profile manifest is observation authority only. It binds the exact
  P4-T08 manifest SHA-256
  `8a53f7519a3b6597d3382c9e91df356474d7d1e72e8ce5d0055e30ef635a1045`; the
  runner verifies the repository P4-T08 path and rejects an alternate profile
  manifest path before sampling.
- The profile uses ten warmups and one hundred measured solves. Profile mode
  rejects `--warmup` and `--measure` overrides so the versioned protocol cannot
  be silently changed.
- Solver construction, manifest validation, and the deterministic reference
  solve occur outside the measured loop. Each measured sample calls the public
  `SpatialEigenSolve.TrySolve` path through the existing converged/usable-state
  validation wrapper. `Stopwatch` and
  `GC.GetAllocatedBytesForCurrentThread` are measurement tools only.
- Timing and allocation p50/p95 values use the manifest's nearest-rank rule.
  The 48-byte flux-state descriptor means one double array per group over three
  nodes: two arrays total, three doubles each. It excludes object overhead and
  is a workload descriptor, not a complete managed-memory census.
- Every sampled result is compared exactly with the reference eigenvalue,
  total power, group flux arrays, and solver iteration count. This is a
  determinism check, not a new golden or reference authority.
- The external profiler availability check found `dotnet-trace`,
  `dotnet-counters`, `dotnet-gcdump`, and `perfview` unavailable. The report
  therefore leaves loop-level hotspots and phase allocation attribution as
  `NotMeasured`; end-to-end solve timing is not presented as a hotspot claim.
- Android remains `Deferred/NotAvailable`: no `adb` command or representative
  Android device is available. Desktop observations are not substituted for
  T5/G9 device evidence.
- Literature applicability: `NotApplicable`. This task consumes the frozen
  synthetic P4-T08 solver contract and selects no physics equation, constant,
  unit, normalization, convergence rule, tolerance, reference case, or golden
  value.
