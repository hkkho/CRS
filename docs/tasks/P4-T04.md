## Assumptions and design choices

- The implementation reuses the frozen P2-T02 convergence definitions: k
  absolute or relative change is an OR condition, while residual, source
  shape, and power balance are all required. No tolerance, equation, unit,
  normalization, or golden value was invented.
- `SpatialConvergencePolicy` accepts only caller-supplied positive finite
  tolerances and a positive iteration limit. Runtime numerical failure and
  nonconvergence return a valid result wrapper carrying diagnostics, but no
  failed/nonconverged final state is marked usable.
- Residual relative measures are zero-safe, source shape is computed in the
  prescribed `s_i = V_i F_i / Q` ordering, and scalar/flux diagnostics reject
  NaN, infinity, and negative flux before state use.
- The existing P2 path has no implemented clamps or upscatter rejection;
  those diagnostic counters therefore remain explicit zero values rather than
  being silently omitted.
- Applicable P1-T08 digest rows were `S1-R03`, `S1-R04`, `S1-R05`, `S1-R06`,
  `S5-R02`, `S5-R03`, `S5-R04`, `S6-R03`, and `S6-R04`. They supplied
  background/context only for the topology and two-group methodology. No
  literature numeric result, equation authority, tolerance, reference case,
  or golden value was selected from them.
- G2 remains exactly `FORCED CLOSED / WAIVED`; P4-T04 consumes the already
  frozen P2 inputs and does not treat the waiver as technical approval.
