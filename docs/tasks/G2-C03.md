## Assumptions and design choices

- G2-C03 remained limited to the G2 RRS queue/equal-time-ordering finding and
  the serialization evidence needed to make that contract implementable.
- Equal-time ranks are `Burnup=0`, `Refuelling=1`,
  `ControllerCommandGeneration=2`, `ActuatorMotion=3`,
  `BranchUpdate=4`, `SpatialSolve=5`, and
  `KineticNuclideStep=6`.
- An automatic controller event uses the measurement snapshot frozen before
  same-time rank-0/rank-1 commits. Manual/scheduled events bind the post-rank-1
  event pre-state.
- Physical state first advances through the elapsed interval under the command
  available before the event. A newly due command becomes available only for
  intervals beginning at that event time; zero delay creates no retroactive or
  instantaneous physical jump.
- `RRSQueueStateV1` is authoritative for available commands,
  `LastMotionTime`, pending records, immutable/current sequence state,
  `AppliedSourceEventIds`, `AllocatedCommandIds`, and `QueueDigest`.
- `GenerationCadenceOrNA` is queue state, not a repeated command field.
  Queue-owned zone/adjuster available-command and motion-time values are
  read-only owner projections, not duplicate mutable state.
- Command IDs use deterministic domain-separated UUIDv8 derivation; command and
  queue digests include schema magic/version and complete canonical state.
- No numerical tolerance, production controller value, or reference result was
  selected or changed.
