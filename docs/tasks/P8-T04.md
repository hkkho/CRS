`save`, `load`, and `replay` commands. The archive is canonical versioned JSON

## Assumptions and design choices

- The archive stores deterministic command intent rather than a second copy of
  mutable simulation state. Replaying from the frozen scenario identity and
  approved parameter hashes reconstructs the existing P8-T02/P8-T03 runtime,
  including hidden pending-action/scoring state, without changing Core state
  contracts.
- The schema is `reactorsim.p8-replay-archive/v1`, with fixed root and
  command-property order. Duplicate, unknown, reordered, missing, trailing,
  commented, wrong-type, nonfinite, unsupported, and over-capacity data is
  rejected before replay.
- The closed command set is `advance_wall`, `set_power_target`,
  `set_tilt_target`, `set_playback_mode`, `pause`, and `resume`. Successful
  commands are recorded in order; failed commands and inspection/save/load/
  replay commands are not recorded as runtime intent.
- The digest binds the scenario/scoring artifact hashes, initial playback mode,
  complete ordered command kind/payload list, final public scored-runtime
  observables, score fields, loss records, and turn-summary fields. This also
  detects a tampered initial mode that is later reset by an explicit command.
- `load` is atomic at the CLI session boundary: current state is untouched on
  any parse, identity, hash, command, runtime, or final-digest failure.
  `replay` uses the same candidate path and never installs the candidate.
- The archive command capacity is 4096. The CLI checks capacity before
  mutating runtime state, so the 4097th state-changing command fails closed.
- `save <path>` and `load/replay <path>` use the existing whitespace-tokenized
  CLI command grammar; a path is therefore one command token. No shell quoting
  or path normalization behavior beyond `Path.GetFullPath` was added.
- Literature applicability: `NotApplicable`. This task consumes frozen
  non-physics gameplay contracts and does not select, change, validate, or
  compare physics equations, constants, units, tolerances, reference cases, or
  golden data.
