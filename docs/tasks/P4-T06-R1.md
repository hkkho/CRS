## Assumptions and design choices

- The project-owner statement in the current request is the recorded project
  authorization for the exact P1-T03 selected artifact set named by
  `reference/donjon5/P1-T03-AFA_180_310_type1_dual.case.json`: the deck,
  assertion procedure, AFA_180/AFA_310 prepared group constants, and derived
  offline comparison/interpolation artifacts produced by later authorized
  tasks. This is a project decision record, not independent legal advice.
- The exact reference inputs and raw outputs remain offline artifacts. Later
  tasks may use path-free labels, lengths, and SHA-256 values in committed
  manifests; they must not place private host paths or raw payloads in the
  runtime package.
- The final game runtime consumes only a compact, versioned, validated reduced
  data product. DONJON5/DRAGON5 executables and source remain offline tools.
- The reduced model and interpolation transformations remain unselected. The
  next physics task must bind them to P2-T01/P2-T02/P2-T03/P2-T05 and may not
  loosen a tolerance or promote candidate data to golden evidence.
- P1-T08 digest applicability is `NotApplicable`: this task records project
  authorization and artifact handling only; it extracts no physics claim and
  changes no numerical behavior.
- G2 remains exactly `FORCED CLOSED / WAIVED`.
