## Assumptions and design choices

- The policy authority is `ProjectAuthoredSyntheticApprovedParameterAuthority`
  with `literature_applicability: NotApplicable`. It is a gameplay regression
  baseline only and is not a physical, production, external-reference, or
  golden-reactor authority.
- The policy artifact is immutably bound to SHA-256
  `d0e6dec7199751ca0f5d5418892fe0210831e46153ff445ec13e4e84ddf49d39`, and to
  the exact approved P8-T02 scenario SHA-256
  `80981452f4808fae9e2c8341fc32e88640b446d386f9dbb7726c1550a2ff51a2` and
  P8-T03 scoring SHA-256
  `4b0f6d0aa3336b0560ca763bfdbf5012151289bbe9122cb1126c13f86086b91c`.
- The closed policy action set is only `set_power_target` and
  `set_tilt_target`, scheduled at strictly increasing explicit wall-time
  offsets and bounded by an explicit horizon. The runner uses the existing
  approved runtime APIs and appends the same replay commands used by P8-T04.
- JSON objects use fixed property order and reject duplicate, unknown, missing,
  reordered, commented, trailing, wrong-type, nonfinite, unsupported,
  over-horizon, over-capacity, and hash-mismatched data. Expected outcomes are
  limited to resolved `SurvivedScenarioHorizon`/`RecordLoss`; expected times,
  score, loss, and turn observables are bounded by the frozen P8 contracts.
- Literature applicability: `NotApplicable`. This task consumes frozen
  synthetic gameplay contracts and selects no physics equation, constant,
  unit, normalization, tolerance, reference case, or external source.
