## Assumptions and design choices

- The user authorization in this task selects the first one-purpose task from
  the approved Phase 8 CLI work package. `P8-T01` is recorded in the current
  scope register; the Phase 8 plan does not authorize the complete game loop in
  one change.
- `SyntheticFixtures.CreateTwoChannelThreePosition()` is used only as an
  explicit, deterministic inspection fixture. It is labeled
  `synthetic-inspection` and is not presented as production CANDU data,
  external authority, or a physics result.
- The command grammar is deliberately limited to the seven commands listed in
  the output help. `advance time`, `refuel`, RRS actions, save/load, replay,
  scenarios, scoring, scripted policies, and soak behavior remain deferred.
- All CLI line-oriented output is written with canonical `\n` separators and
  invariant numeric formatting. Malformed commands write diagnostics only to
  stderr and return exit code `2` after input processing; valid sessions return
  `0`.
- `P1-T08` applicability is `NotApplicable`: this task selects no equation,
  coefficient, map, unit, sign, normalization, convergence rule, tolerance,
  reference case, golden value, or nuclear-data behavior.
