# XSEC-MAP-R2 owner approval - SPH-preserving mapping reconciliation

**Recorded:** 2026-08-27  
**Decision:** APPROVED / BOUNDED

## Owner direction

The repository owner has explicitly authorized creation and execution of a new
bounded specification to resolve the `XSEC-03-R2` authority conflict. The
replacement must preserve the two source `SPH` transitions required by the
official JEFF `TCWUX11` regression while identifying only demonstrably
pre-transition capture records that may be decoded by the later, separate
`XSEC-03-R2` execution.

This decision authorizes the project to select the resulting candidate
two-knot source profile when it is supported by the completed `XSEC-SPH-03`
capture evidence and exact external source record. It is a project-owner
technical direction, not an external legal opinion.

## Bounded authority

`XSEC-MAP-R2` may create replacement source-to-runtime mapping and
lattice-deck authorities, a path-free specification manifest, and the
associated report/scope routing. It may retain the official source case,
library identity, group structure, units, field transformations, Core
exclusions, source assertions, and fail-closed rules already established by
the reviewed XSEC chain.

It may replace only the incompatible instruction to delete source `SPH` calls
and the resulting unsupported seven-knot source selection. It may define the
exact captured selections at source elapsed days 0 and 300, provided it keeps
the source transitions intact and rejects all other source records.

## Non-authorization

This authority does not authorize a DRAGON/DONJON rerun, source decoding,
runtime pack, Core/CLI/Unity change, new public schema, reference/golden
baseline, tolerance, release, publication, data redistribution, or a claim
that the candidate is licensed for distribution, real, authoritative, golden,
or Unity-ready. Those remain separate tasks and gates. Raw JEFF/WLUP data,
modified decks, LCM serializations, source listings, executables, and generated
cross-section values remain external to the repository.

Any unresolved source-object, unit, group, field, normalization, convergence,
or licensing conflict remains a fail-closed stop for the affected later task.
