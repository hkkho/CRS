## Assumptions and design choices

- Queue state is immutable. A successful enqueue or motion/consume operation
  returns a new validated queue and leaves the input queue byte-for-byte
  unchanged; any validation failure returns only a deterministic diagnostic.
- Queue families use the frozen ranks and domain separators: RRS rank 2,
  liquid-zone/adjuster rank 4, with actuator motion rank 3 for RRS and branch
  rank 4 for the branch families.
- `P6T06SourceBindingTokenV1` is an explicit adapter-level precondition. The
  owning controller/branch adapter must validate the frozen measurement or
  event pre-state and supply its exact digest; P6-T06 preserves and binds that
  event/digest pair without inventing a measurement or physics rule.
- `P6T06QueuePhaseTokenV1` binds enqueue to the current queue digest and exact
  event time. Closing the token represents the frozen due-batch cutoff and
  prevents a raw caller Boolean from reopening same-time admission.
- Branch queue ordering is a non-mutating projection sorted by typed owner
  kind, owner identity, and queue identity. Cross-queue scenario execution and
  refuelling interaction remain deferred to their owning task/gate.
- Synthetic values in the focused tests are contract fixtures only. They do
  not authorize production CANDU maps, controller gains, comparisons, or
  golden data.
