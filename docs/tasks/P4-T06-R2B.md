# P4-T06-R2B - CANDU source-to-Core mapping and authority audit

## Outcome

Status: BLOCKED

This bounded audit produced a materially stronger CANDU reference candidate but
did not complete solver-ready admission. The same pinned DONJON5 Version5
source tree contains the Candu6.x2m case, which runs successfully in the
pinned container and explicitly produces the production-sized fuel map:
380 fuel channels, 12 bundles per channel, and 4560 total bundles. The run
also emits 380 channel-power values and 4560 bundle-power values.

The audit does not prove the frozen P2-T02 source-to-Core mapping. The
DONJON/CPO records expose volumes, multigroup macrolib fields, and source
power outputs, but no authority-backed export binds them to the Core's
preassembled T_g/B_g conductances in m^2, node V_i in m^3, per-fission E_f,i
in J, explicit ChannelId/BundlePosition identity, and the P2 observable and
normalization contracts. The missing authority is now isolated as P4-T06-R2C.

The earlier P4-T06-R2A report is preserved. R2A selected candu6_iram as a
CANDU-contextual profile. R2B inspected the additional same-pinned Candu6.x2m
case and records it as the stronger candidate for the final mapping task
because it matches the frozen 380 x 12 production counts. This is a current
handoff decision, not a rewrite of R2A's historical applicability record.

Effectiveness: BLOCKED

### Source-to-Core authority audit

| P2-T02 quantity or contract | Observed source evidence | Admission result |
|---|---|---|
| V_i in m^3 | DONJON tracking documentation identifies VOLUME in cm^3. The source run exposes a VOLU-BUND vector of length 4560 and total core volume in cm^3. | Counts and source units are identified, but no path-free manifest binds each source volume to one P2 node identity and the required SI value. Do not silently convert or assume bundle volume equals Core node volume. |
| E_f,i in J | CELNAT contains ISOTOPES-EFJ records. The source package also contains fission-energy-related macrolib records. | The source record is not an approved per-node, per-fission J binding for P2. An explicit source convention and node-level export are required. |
| T_g and B_g in m^2 | Source documentation defines STRD and explains a diffusion-coefficient construction; CPO/macrolib records contain cross-section/diffusion-related fields. | P2-T02 requires preassembled edge and boundary conductances and forbids an unapproved geometry formula from D_g. No source field or export in this audit binds T_g/B_g. |
| ChannelId/BundlePosition and direction | The run proves NB=12, NCH=380, NTOT=4560 and prints channel/bundle coordinates for maxima. | Production counts match, but source array order and coordinate/index conventions are not an approved explicit P2 identity map or flow-direction map. |
| Node-level observables | POWER-CHAN has length 380, POWER-BUND has length 4560, POWER-DISTR has length 29040, and the source reports power in W. | These are strong candidate outputs, but no manifest binds POWER-BUND to P2 P_i, scope, ordering, or normalization. |
| Normalization | The source reports GIVEN TOTAL REACTOR POWER 2.06139994E+09 WATTS and COMPUTED TOTAL POWER 2.06139990E+09 WATTS. | The approximately 40 W source-internal difference (about 1.9e-8 relative) is not a project tolerance and is not a Core comparison. The P2 target-power binding remains unproved. |

The external IGE351 documentation supplies useful source semantics:
SectDtracking.tex identifies VOLUME as cm^3; SectDmicrolib.tex identifies
NUSIGF, NFTOT, and STRD as barns and NWT0 as s^-1 cm^-2; its STRD section
describes a source-specific diffusion construction. Those facts explain the
source records but do not create the missing P2-T02 conductance or node
mapping authority.
