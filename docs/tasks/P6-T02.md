### Assumptions and design choices

- The P6-T01 grouping and state contracts remain the prerequisite authority;
  no P6-T01 equation, field, or grouping was changed.
- The owner approval authorizes only the exact synthetic fixture. The Core
  validator therefore fails closed on an unapproved map ID, grouping identity,
  topology identity, owner, data version, units, sign certificate, reference
  profile, entry values, missing/duplicate key, or digest mismatch.
- Canonical bytes use UTF-8 strings without a BOM, little-endian unsigned
  integer fields, IEEE-754 binary64 little-endian doubles, explicit length
  prefixes for strings/byte fields, and canonical ordering of targets and
  entries.
- The map digest is SHA-256 over the map body with the final `MapDigest` field
  excluded; the digest is appended only in the serialized complete map bytes.
  Its exact body order is: schema, map ID, mapping ID, mapping version,
  mapping digest, topology ID, topology digest, data version, owner ID, sign
  certificate, source unit, target unit, reference-state digest, reference
  fills, target nodes, and ordered entries. The reference-state digest has its
  own recorded order in the package canonicalization object and excludes the
  map digest to avoid circularity.
- Overlay aggregation uses a preallocated six-by-two accumulator and then
  emits explicit target/group values in canonical order. Disabled zones are
  skipped before contribution and retain exact serialized zero assertions.
- Motion is intentionally a pure projection over the supplied command
  projection and explicit command-available time. A not-yet-due command cannot
  move the physical state; P6-T06 owns queue transition/consumption and the
  authoritative timing projection.
- The implementation makes no coolant-flow, thermal-hydraulic, shutdown,
  scram, accident, operator-training, or direct-reactivity behavior claim.
