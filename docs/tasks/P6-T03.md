### Assumptions and design choices

- The owner-approved values are synthetic fixture values only. The Core
  validator admits only the approved IDs, grouping content, target topology,
  metadata, units, sign certificate, reference fractions, positive weights,
  and canonical digests.
- Source fractions and reference fractions are dimensionless; overlay targets
  are `m^-1`; rate is fraction/s; delay, update, queue-motion, and event times
  are SI seconds. `Normalization` is explicitly `None`.
- `GenerationCadenceOrNA` is explicit in the complete queue state. This
  fixture uses `NotApplicable`; an applicable automatic cadence must be finite
  and strictly positive.
- RateLimited motion reads the complete queue's bounded available command,
  rate, bounds, queue-owned last-motion time, and digest. It projects state
  without allocating, enqueuing, consuming, transitioning, or rolling back
  queue state.
- The local overlay consumes `StateFraction - ReferenceFraction` only and
  preserves exact serialized input bytes. Disabled banks contribute exact
  zero. Scratch evaluation and failure-path byte preservation are local
  evidence, not shared queue rollback.
- Canonical bytes use the existing Core field-tagged UTF-8/SHA-256 helper,
  explicit type/length fields, IEEE-754 binary64 values, and stable identity
  ordering. Digest fields are excluded only while their own digest is being
  computed.
