Editor `6000.3.21f1` (revision `c02631ffc030`) and adds two parseable,

## Assumptions and design choices

- The exact Unity editor/revision remains the P0-T05 pin in
  `unity/toolchain.json`; this task documents it but does not add a mobile
  module or independently pin SDK/NDK/JDK installations.
- Both templates use top-level integer `version: 1` as an example-format
  version. Application identifiers, application versions, build numbers, and
  output paths remain obvious placeholders.
- Template `signing` values are environment-variable names only. Real signing
  inputs stay in a secure local or CI secret store and are never copied into the
  repository, logs, or this report.
- The document cites only current primary Unity, Android, and Apple sources
  consulted on 2026-08-07. It treats the templates as documentation, not a
  public schema or automatic build integration.

## Validation commands and results

### JSON template parsing and shape assertions - T0/T1

```powershell
$ErrorActionPreference = 'Stop'
function Require([bool]$condition, [string]$message) {
    if (-not $condition) { throw $message }
}

$specifications = @(
    @{
        File = 'unity/build-config/android.example.json'; Platform = 'android'
        Application = @{ identifier = 'String'; versionName = 'String'; versionCode = 'Integer' }
        Output = @{ path = 'String'; format = 'String' }
        Signing = @('keystorePathEnvironmentVariable', 'keystorePasswordEnvironmentVariable', 'keyAliasEnvironmentVariable', 'keyAliasPasswordEnvironmentVariable')
    },
    @{
        File = 'unity/build-config/ios.example.json'; Platform = 'ios'
        Application = @{ identifier = 'String'; bundleVersion = 'String'; buildNumber = 'Integer' }
        Output = @{ xcodeProjectPath = 'String'; archivePath = 'String' }
        Signing = @('teamIdentifierEnvironmentVariable', 'signingCertificateEnvironmentVariable', 'provisioningProfileSpecifierEnvironmentVariable')
    }
)

foreach ($specification in $specifications) {
    $config = Get-Content -Raw -LiteralPath $specification.File | ConvertFrom-Json
    Require ($config.version -is [int] -and $config.version -eq 1) "$($specification.File): version must be integer 1."
    Require ($config.platform -is [string] -and $config.platform -eq $specification.Platform) "$($specification.File): unexpected platform."
    Require ($config.developmentBuild -is [bool] -and $config.developmentBuild) "$($specification.File): developmentBuild must be Boolean true."
    Require ($null -ne $config.application -and $null -ne $config.output -and $null -ne $config.signing) "$($specification.File): required object missing."
    foreach ($field in $specification.Application.GetEnumerator()) {
        $value = $config.application.($field.Key)
        $valid = if ($field.Value -eq 'String') { $value -is [string] -and -not [string]::IsNullOrWhiteSpace($value) } else { $value -is [int] -and $value -gt 0 }
        Require $valid "$($specification.File): application.$($field.Key) has the wrong type or value."
    }
    Require ($config.application.identifier -match '^com\.example\.[a-z0-9]+$') "$($specification.File): identifier is not a placeholder."
    foreach ($field in $specification.Output.Keys) {
        $value = $config.output.$field
        Require ($value -is [string] -and -not [string]::IsNullOrWhiteSpace($value)) "$($specification.File): output.$field is missing."
        Require (-not [System.IO.Path]::IsPathRooted($value) -and $value -notmatch '^(?:[A-Za-z]:[\\/]|/|~[\\/]|\\\\)') "$($specification.File): output.$field is not repository-relative."
    }
    foreach ($field in $specification.Signing) {
        $value = $config.signing.$field
        Require ($value -is [string] -and $value -match '^REACTORGAME_(?:ANDROID|IOS)_[A-Z0-9_]+$') "$($specification.File): signing.$field is not an environment-variable name."
    }
}
Write-Output "PASS: $($specifications.Count) JSON templates parsed; required keys, types, platform values, placeholders, relative outputs, development flags, and signing-variable names validated."
```

Result: exit code 0. Both JSON examples parsed. Required keys and types,
platform values, placeholder identifiers, repository-relative output paths,
Boolean development-build flags, and signing environment-variable-name values
all passed.

### Credential-fingerprint and absolute-user-path scan - T0

```powershell
$ErrorActionPreference = 'Stop'
$files = @(
    'docs/platforms/mobile-build-prerequisites.md',
    'docs/tasks/P0-T06.md',
    'unity/build-config/android.example.json',
    'unity/build-config/ios.example.json'
)
$absoluteUserPathPatterns = @(
    '(?im)[A-Za-z]:\\Users\\',
    '(?im)(?<![A-Za-z0-9])/(?:Users|home)/',
    '(?im)\\\\[^\\\r\n]+\\(?:Users|home)\\'
)
$credentialFingerprints = @(
    '-----BEGIN(?: [A-Z]+)* PRIVATE KEY-----',
    '\bAKIA[0-9A-Z]{16}\b',
    '\bgh[pousr]_[A-Za-z0-9_]{20,}\b',
    '\bxox[baprs]-[A-Za-z0-9-]{10,}\b',
    '\bAIza[0-9A-Za-z_-]{35}\b'
)
foreach ($file in $files) {
    $content = Get-Content -Raw -LiteralPath $file
    foreach ($pattern in $absoluteUserPathPatterns) {
        if ([regex]::IsMatch($content, $pattern)) { throw "$file contains an absolute user path." }
    }
    foreach ($pattern in $credentialFingerprints) {
        if ([regex]::IsMatch($content, $pattern)) { throw "$file contains a credential fingerprint." }
    }
}
Write-Output "PASS: scanned $($files.Count) added files; no credential fingerprints or absolute user paths found."
```

Result: exit code 0. The scan found no credential fingerprint or absolute user
path. The JSON-shape check above separately verifies that signing values are
environment-variable names rather than secret values.

### Markdown-link syntax and local-target validation - T0

```powershell
$ErrorActionPreference = 'Stop'
$files = @(
    'docs/platforms/mobile-build-prerequisites.md',
    'docs/tasks/P0-T06.md'
)
$linkCount = 0
foreach ($file in $files) {
    $content = Get-Content -Raw -LiteralPath $file
    $matches = [regex]::Matches($content, '\[(?<label>[^\]]+)\]\((?<target>[^)\r\n]+)\)')
    $baseDirectory = Split-Path -Parent (Resolve-Path -LiteralPath $file)
    foreach ($match in $matches) {
        $linkCount++
        $label = $match.Groups['label'].Value
        $target = $match.Groups['target'].Value
        if ([string]::IsNullOrWhiteSpace($label) -or [string]::IsNullOrWhiteSpace($target)) {
            throw 'Found a Markdown link with an empty label or target.'
        }
        if ($target -match '\s') { throw "Markdown link target contains whitespace: $target" }
        $uri = $null
        if ([Uri]::TryCreate($target, [UriKind]::Absolute, [ref]$uri)) {
            if ($uri.Scheme -notin @('http', 'https')) { throw "Markdown link uses unsupported URI scheme '$($uri.Scheme)'." }
        }
        else {
            $relativeTarget = $target.Split('#')[0]
            if (-not [string]::IsNullOrWhiteSpace($relativeTarget)) {
                $resolvedTarget = Join-Path $baseDirectory $relativeTarget
                if (-not (Test-Path -LiteralPath $resolvedTarget)) { throw "Markdown relative link target does not exist: $target" }
            }
        }
    }
}
if ($linkCount -eq 0) { throw 'No Markdown links were found.' }
Write-Output "PASS: $linkCount Markdown links are syntactically valid; local targets resolve."
```

Result: exit code 0. All 23 Markdown links had a nonempty label/target,
acceptable URI syntax, and resolving local targets.

### Pinned editor and mobile-module absence inspection - T0

```powershell
$ErrorActionPreference = 'Stop'
$editor = Join-Path $env:LOCALAPPDATA 'Unity\Editors\6000.3.21f1\Editor\Unity.exe'
if (-not (Test-Path -LiteralPath $editor -PathType Leaf)) { throw 'Pinned Unity editor is missing.' }
$productVersion = (Get-Item -LiteralPath $editor).VersionInfo.ProductVersion
if ($productVersion -ne '6000.3.21f1_c02631ffc030') { throw "Unexpected editor product version: $productVersion" }
$playbackEngines = Join-Path (Split-Path -Parent $editor) 'Data\PlaybackEngines'
foreach ($mobileModule in @('AndroidPlayer', 'iOSSupport')) {
    if (Test-Path -LiteralPath (Join-Path $playbackEngines $mobileModule)) { throw "$mobileModule was installed unexpectedly." }
}
$installed = @(Get-ChildItem -LiteralPath $playbackEngines -Directory | Select-Object -ExpandProperty Name)
Write-Output "PASS: pinned editor $productVersion is installed; AndroidPlayer and iOSSupport are absent. Playback engines: $($installed -join ', ')."
```

Result: exit code 0. The pinned editor product version matched exactly;
`AndroidPlayer` and `iOSSupport` were absent. The only installed playback engine
was `windowsstandalonesupport`, confirming that this task did not install either
mobile module.
