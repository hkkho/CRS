## Assumptions and design choices

- P2-T05 defines observable identity and validation contracts only. It does not
  approve numeric tolerances, golden data, runtime equations, or reference
  values; numeric profiles remain provisional/deferred until their owner gates.
- The closed 135-quantity crosswalk has explicit per-`QuantityId` value kinds
  and payload schemas. Invariant, rollback, saturation, disabled-zero, parser,
  provenance, and event evidence use typed structured payloads rather than a
  lossy Boolean or scalar fallback.
- Aggregate vectors use record-level `ComponentKey=NotApplicable`; concrete
  ordered component keys are carried in the vector payload and in the record
  scope. Profile component-order bytes contain reusable key schema/comparator
  metadata, not topology-specific counts or keys.
- Region-power sums bind an ordered, disjoint, complete region partition.
  `spatial.delta_k_abs` and `spatial.delta_k_rel` bind consecutive finite
  solver `k` values and use the explicit `WhenConsecutiveKPair` applicability;
  no threshold was invented.
- Event, scope, entity/vector subtype, structured-field, status-enum, UUID,
  width, and invariant-ordinal encodings are closed and fail closed on missing,
  duplicate, reordered, non-finite, or incompatible data.
