### Gate/task report structure and links - T0

```powershell
$reportFiles = @('docs/gates/G0.md', 'docs/tasks/G0.md')
$linkCount = 0
foreach ($file in $reportFiles) {
    $content = Get-Content -Raw -LiteralPath $file
    if (([regex]::Matches($content, '(?m)^```').Count % 2) -ne 0) {
        throw "$file has unbalanced code fences."
    }
    if (Get-Content -LiteralPath $file | Where-Object { $_ -match '[ \t]+$' }) {
        throw "$file contains trailing whitespace."
    }
    $base = Split-Path -Parent (Resolve-Path -LiteralPath $file)
    foreach ($match in [regex]::Matches(
            $content, '\[[^\]]+\]\((?<target>[^)\r\n]+)\)')) {
        $linkCount++
        $target = $match.Groups['target'].Value
        $uri = $null
        if ([Uri]::TryCreate($target, [UriKind]::Absolute, [ref]$uri)) {
            if ($uri.Scheme -notin @('http', 'https')) {
                throw "Unsupported link: $target"
            }
        }
        else {
            $relative = $target.Split('#')[0]
            if ($relative -and
                -not (Test-Path -LiteralPath (Join-Path $base $relative))) {
                throw "Missing local link: $target"
            }
        }
    }
}
Write-Output "PASS: $linkCount Markdown links validated."
```

Result: exit code 0. Both reports contained the required template sections,
balanced code fences, no trailing whitespace, and four valid Markdown links
whose local targets resolved.

### Final scope inspection - T0

```powershell
$repositoryRoot = (Get-Location).Path
$snapshot = Join-Path $validationRoot 'clean-source'
$current = @(
    git status --porcelain=v1 --untracked-files=all |
        ForEach-Object {
            if (-not $_.StartsWith('?? ')) { throw "Unexpected status: $_" }
            $_.Substring(3)
        } |
        Sort-Object
)
$expectedNew = @('docs/gates/G0.md', 'docs/tasks/G0.md') | Sort-Object
$baseline = @($current | Where-Object { $_ -notin $expectedNew })
if ($baseline.Count -ne 83) { throw "Expected 83 baseline files." }
foreach ($relative in $baseline) {
    $currentPath = Join-Path $repositoryRoot $relative
    $snapshotPath = Join-Path $snapshot $relative
    if (-not (Test-Path -LiteralPath $snapshotPath -PathType Leaf)) {
        throw "Baseline path is absent from the snapshot: $relative"
    }
    if ((Get-FileHash -Algorithm SHA256 $currentPath).Hash -ne
        (Get-FileHash -Algorithm SHA256 $snapshotPath).Hash) {
        throw "Pre-existing file changed: $relative"
    }
}
$actualNew = @($current | Where-Object { $_ -in $expectedNew } | Sort-Object)
if (Compare-Object $expectedNew $actualNew) { throw 'G0 scope mismatch.' }
```

Result: exit code 0. All 83 pre-existing Git-visible files remained
byte-identical to the pre-report isolated snapshot; exactly the two G0 report
files were added, producing 85 visible paths. No corrective-task or Phase 1 file
was created.

Two preliminary read-only audit helpers were corrected before this final scope
run: one matched prose from `dotnet list` instead of inspecting project XML, and
one matched the external snapshot's parent `Temp` directory instead of comparing
repository-relative paths. The corrected XML and relative-path checks above
passed; neither attempt changed a repository file.
