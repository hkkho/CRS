## Assumptions and design choices

- The existing `Phase8UnityPresentationSnapshotV1` is the sole data authority;
  no snapshot fields, schema versions, units, constants, or public Core/CLI
  contracts were added.
- `Bind` requires an already-bound adapter with a non-null immutable snapshot,
  subscribes to `SnapshotChanged`, and renders the current snapshot
  immediately. `Unbind` removes the event subscription, clears the snapshot,
  and replaces stale labels with explicit unavailable text.
- The Dashboard is attached to the shell's Dashboard page root only after
  explicit binding. The scene's adapter/view components are intentionally
  inert until a future host supplies the approved runtime port.
- Formatting is presentation-only: percentages, invariant decimal and integer
  text, explicit wall-control milliseconds, simulation seconds, wall seconds,
  and the approved acceleration factor are displayed without changing their
  runtime values.
- No `Update`, Unity time API, command dispatch, parameter loading, save/load,
  replay, physics, optimization, mobile build, or production claim was added.
- Literature applicability: `NotApplicable`; this task selects no physics
  equation, constant, unit, normalization, reference case, tolerance, or
  golden authority.
