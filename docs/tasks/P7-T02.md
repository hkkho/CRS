## Assumptions and design choices

- The P5-T09 implementation already supplies the approved I/Xe state owner,
  atom inventories, derived densities, data identity/digest, accepted history,
  version progression, and explicit Euler transition. P7-T02 closes its Phase
  7 package boundary rather than duplicating those public contracts.
- P2-T04 remains the runtime authority. `NuclideDataV1` accepts only explicit
  caller/data-pack yields, decay constants, and Xe absorption cross sections;
  no production constant, equilibrium, initial inventory, tolerance, or
  reference value is inferred.
- The local spatial boundary is the existing explicit
  `NuclideIntegrationInputV1` (`R_f`, actual group fluxes, event time/duration,
  core-state binding, and state-binding digest) plus the current envelope's
  P2-T02 node volume. The transition computes atom-rate terms at the frozen
  left endpoint and derives densities from that same volume.
- Zero loss magnitudes use an explicit canonical-zero branch so a legal
  all-zero inventory does not manufacture a signed-negative-zero audit term.
  External negative zero is rejected; no value is silently rounded, clamped,
  or repaired.
- Cross-bundle xenon transport and thermal-hydraulic mixing remain excluded by
  P2-T04. Dynamic Xe absorption in the P2-T02 coefficient set, including an
  explicit xenon-free base-table marker and mandatory post-Xe spatial solve,
  remains a later coupling task.
- Applicable P1-T08 digest rows are `S1-R09`, `S4-R05`, `S4-R06`, and `S5-R08`.
  They remain methodology, context, candidate numeric, or candidate case
  evidence only. They supply no runtime yields, decay constants, cross sections,
  initial conditions, mapping, tolerance, or golden authority. P2-T04 governs.
