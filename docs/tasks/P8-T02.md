## Assumptions and design choices

- The promoted artifact is `ProjectAuthoredSyntheticApprovedParameterAuthority`
  and is limited to gameplay pacing, normalized proxy state, deterministic
  identity, scripted events, action budgets, and loss recording. P1-T08
  literature applicability is `NotApplicable`: this task selects no equation,
  constant, nuclear-data value, physical unit, reference case, or tolerance.
- The approved default is 10 simulation seconds per wall second with a 100 ms
  control tick and a one simulation-second presentation cap. The approved 1x
  audit mode remains available; no faster-than-approved mode was introduced.
- Wall input is an explicit integer millisecond argument. Wall time never comes
  from `DateTime`, `Stopwatch`, Unity frame timing, or a physics timestep. The
  runtime preserves partial control-tick state across pause and discards wall
  duration supplied while paused.
- Action acknowledgement is recorded at queue time, commit is recorded at the
  next control boundary, and queue delay is bounded by one 100 ms tick for the
  tested interactive path. Actions are not allowed while paused or after a
  resolved scenario.
- Scripted events are processed in nondecreasing simulation-time order. At a
  shared boundary, queued actions commit before scripted events. Envelope
  bounds are inclusive; the loss priority is power below, power above, tilt,
  control margin, then device exhaustion.
- Initial-state construction is factory-only and rejects nonfinite and invalid
  domain values. The approved runtime remains a normalized synthetic proxy and
  does not alter the existing solver or physics contracts.
