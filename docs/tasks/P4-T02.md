## Assumptions and design choices

- `SpatialCoefficientSet` accepts only in-memory values bound to the exact
  `SpatialStencil` instance. Data-pack loading, versioning, checksums, and
  serialization remain deferred and no new serialized schema was invented.
- Node coefficients enforce the frozen P2-T02 invariants: finite positive
  volume and fission energy, nonnegative cross sections, absorption greater
  than or equal to fission absorption, exact local chi sum, and matching zero
  support for `Sigma_f`/`nuSigma_f`.
- Each canonical reciprocal interior edge receives one shared positive
  conductance per group. Each explicit boundary face receives exactly one
  conductance per group; reflective faces require zero and vacuum or specified
  leakage faces require positive values.
- Operator application uses the P2-T02 expression
  `Sigma_r * flux + leakage / volume`, with neighbor terms followed by
  boundary terms in the preassembled canonical order. Input and output arrays
  are caller-owned and distinct; every rejected call clears any supplied
  destination buffer.
- The implementation uses `double`, precompiled term arrays, no parallelism,
  no Unity timing, and no hidden geometry or conductance calculation.
- Applicable P1-T08 digest rows are `S1-R03`, `S1-R06`, `S5-R02`, and `S6-R04`
  for topology/case-design context, plus `S1-R04`, `S1-R05`, `S5-R03`,
  `S5-R04`, and `S6-R03` for two-group methodology context. No literature
  number, alternative equation, reference coefficient, tolerance, or golden
  value was used.
- G2 overlap decision: `FORCED CLOSED / WAIVED`. This was administrative
  overlap authorization only, not a technical PASS. The frozen P2-T01/P2-T02
  specifications were implemented without alteration, and no historical G2
  finding was erased.
