# P1-T01 - Pin Version5 provenance and Linux prerequisites

## Outcome

P1-T01 pins the official Version5 source and official library repository, records
their legal and LFS constraints, and documents the upstream Linux build baseline.
No source, executable, container, library asset, case input, output, parser, or
runner was added. The data repository has no standalone license text at the
pinned revision, so this task adopts an explicit no-vendoring/no-redistribution
policy rather than assuming rights from public availability.

## Assumptions and design choices

- `v5.1.0` is a lightweight tag, so the source identity is the exact commit
  `eee582f8594d3b7d01b65660ca1e8bef00eb6b2a` and tree
  `0d3e8f721c84b3c3b2d03e9898a8a0a9c29287d8`, not the tag name alone.
- The library repository is pinned to `main` as observed at commit
  `d4456d42fdcdeb8147ce6e79d3a8ba0e775d403f` and tree
  `ed92fc1c60c373f07276516142a0aa28ba4c2433`; no LFS asset was selected or
  downloaded.
- The official Version5 site/FAQ state LGPL distribution, but the pinned tree
  contains GPL-2.0-or-later third-party Utilib/freesteam notices. The record is
  therefore `NOASSERTION / mixed notices`, not a blanket SPDX claim.
- The official site identifies XMAS/SHEM Draglibs as open-source, but the pinned
  `libraries` tree has no project or per-asset license file. This task makes no
  redistribution inference and requires a separate determination before any
  asset or derived output is published.
- Ubuntu 22.04 is the upstream CI baseline. The optional official prebuilt image
  is identified by digest and observed as `linux/amd64` with OCI version `24.04`;
  the README/Dockerfile base-image discrepancy is recorded instead of hidden.

## Validation commands and results

### Provenance manifest and upstream-pin consistency - T0/T1

```powershell
$probe = 'C:\Users\infin\AppData\Local\Temp\candu-p1-t01-probe-6baa5d14f96d4262b146d47e8c7af775'
$version5 = Join-Path $probe 'version5'
$libraries = Join-Path $probe 'libraries'
$manifest = Get-Content -Raw -LiteralPath `
    'reference/manifests/version5-v5.1.0-provenance.json' | ConvertFrom-Json

if ($manifest.version5_source.pin.commit -ne
    (git -C $version5 rev-parse 'v5.1.0^{commit}')) { throw 'Version5 commit mismatch.' }
if ($manifest.version5_source.pin.tree -ne
    (git -C $version5 rev-parse 'v5.1.0^{tree}')) { throw 'Version5 tree mismatch.' }
if ($manifest.nuclear_data_repository.pin.commit -ne
    (git -C $libraries rev-parse HEAD)) { throw 'Libraries commit mismatch.' }
if ($manifest.nuclear_data_repository.pin.tree -ne
    (git -C $libraries rev-parse 'HEAD^{tree}')) { throw 'Libraries tree mismatch.' }
if ($manifest.nuclear_data_repository.pin.lfs_tracked_path_count -ne
    @(git -C $libraries lfs ls-files -l -s).Count) { throw 'LFS count mismatch.' }
if ($manifest.license_and_redistribution.version5_classification -ne
    'NOASSERTION / mixed notices') { throw 'License classification mismatch.' }
Write-Output 'PASS: JSON parsed; source, tree, LFS count, and legal classification match the audited upstream state.'
```

Result: exit code 0. The JSON parsed; Version5 and libraries commits/trees
matched; 86 LFS-tracked paths were observed; and the conservative mixed-notice
classification was present.
