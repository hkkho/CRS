## Assumptions and design choices

- P2-T04 remains the authority for point-kinetics/I/Xe equations, signs,
  units, explicit initial conditions, and excluded safety behavior. The tests
  call existing transitions; they do not duplicate or alter equations.
- The equilibrium-like startup values are explicit test inputs. The test does
  not calculate, infer, or install an equilibrium initializer; it verifies that
  the supplied values remain deterministic under a zero-reactivity history.
- Power increase and ordinary reduction are represented by explicit spatial
  rebindings with caller-supplied reactivity values. No shutdown state, trip,
  scram, safety system, accident progression, or loss envelope is introduced.
- The xenon history uses explicit atom inventories, material-keyed synthetic
  nuclide data, fission-rate/flux inputs, and the P7-T03 policy partition. Its
  high-power prefix and low-power tail are a synthetic test trace, not a
  reference case, golden value, production scenario manifest, or literature
  mapping.
- Applicable P1-T08 literature rows: `S1-R09` (135Xe methodology/context only),
  `S4-R05` (refuelling/reactivity/device context only), `S4-R06` (blocked
  candidate comparison evidence with no approved baseline), and `S5-R08`
  (candidate case-design context with no runtime mapping). These rows authorize
  no scenario numbers or runtime baseline; P2-T04 remains authoritative.
