## Assumptions and design choices

- `CoreTopology` is the only accepted input; its existing validator remains
  authoritative for IDs, reciprocal relations, boundary coverage, and face
  labels. The new assembly does not duplicate or weaken that validation.
- Nodes use the P2-T02 canonical order: ascending channel ID, then ascending
  bundle position. Neighbor terms use the explicit direction ranks followed by
  target channel and target position; boundary terms use the explicit face
  ranks.
- The assembly stores target `NodeKey` and target flat index together so later
  coefficient application cannot infer adjacency from array position.
- Returned node and term collections defensively copy their inputs into
  read-only collections. No mutable queue/state transition or solver result is
  introduced.
- Applicable P1-T08 digest rows are `S1-R03`, `S1-R06`, `S5-R02`, and `S6-R04`
  for topology/case-design context, plus `S1-R04`, `S1-R05`, `S5-R03`,
  `S5-R04`, and `S6-R03` for two-group methodology context. No literature
  number, equation variant, coefficient, unit conversion, tolerance, or
  golden value was used; the frozen P2 specifications remain authoritative.
- G2 overlap decision: `FORCED CLOSED / WAIVED`. This was treated as
  administrative overlap authorization only, not as a technical PASS. The
  existing P2 specifications were consumed unchanged; no G2 technical finding
  was erased or reinterpreted.
