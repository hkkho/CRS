## Assumptions and design choices

- The three admitted cases are homogeneous across all three nodes and all
  boundaries are reflective, as bound by G4C and the P4-T08 fixture. The
  uniform spatial mode therefore has zero leakage contribution; this is a
  property of the admitted fixture, not a new runtime boundary rule.
- The frozen P2-T02 equations are represented as `L phi = (1/k) B phi`, then
  evaluated as `B phi = k L phi` for the uniform mode. The lower-group
  downscatter term remains in `L`; it is not incorrectly treated as a fission
  source or multiplied into a new physical equation.
- Material coefficients and the 25000 J/kg HM midpoint use the existing R4
  pack and its established interpolation formula. The G4D candidate is read
  only for diagnostic comparison; analytical values are recomputed from the
  hash-bound pack and benchmark inputs.
- The existing P2-T02 power formula and target `0.9 W` are used for amplitude
  normalization. No convergence tolerance is used to classify the analytical
  result, and raw differences are reported without a pass threshold.
- The tool is offline evidence only. It does not modify `ReactorSim.Core`, the
  runtime data contract, the Unity adapter, `data/golden`, or any reference
  tool dependency.
