## Exact case and normalization mapping

All three admitted cases use the same explicit topology and the same caller
target power of 0.9 W. All three nodes have the same burnup in their case
vector, so no mixed-state or refuelling transition is inferred.

| R5 case | Scenario class | Burnup by node (J/kg HM) | Lookup bracket in MAT-SYN | Interpolation alpha | Case status |
| --- | --- | --- | --- | ---: | --- |
| fresh_candidate | fresh | [0, 0, 0] | 0 to 0 | 0 | CandidateSnapshot |
| equilibrium_like_candidate | equilibrium_like | [50000, 50000, 50000] | 50000 to 50000 | 0 | CandidateSnapshot; representative knot only, not inferred equilibrium |
| midcycle_interpolation_candidate | interpolation_midpoint | [25000, 25000, 25000] | 0 to 50000 | 0.5 | CandidateSnapshot |

The lookup is the existing P5-T05/R3 contract: an exact knot uses that row;
an in-domain point uses the existing lower/upper knot interpolation and
alpha calculation. The three-row source/pack domain is 0, 50000, and 100000
J/kg HM. G4D must fail closed for an out-of-domain, non-finite, invalid, or
incoherent lookup.

The normalization mapping is:

- P2-T02 owns the normalization rule alpha = P_target / P_total.
- P4-T08 supplies the caller-owned target P_target = 0.9 W for this fixture.
- The R4 MAT-SYN row selected by each case supplies the material energy per
  fission and other material coefficients used by the reduced solve. The
  P4-T08 benchmark's synthetic coefficient fields, including its
  energy-per-fission field, are not substituted for the R4 table.
- Node volume is 1.0 m3 and the stored/output units are the existing SI-v1
  and P2-T05 units. No external power normalization or hidden scale is added.
- G4D must record the target, pre-normalization total power, normalization
  scale, post-normalization total power, and any invalid or nonconverged
  diagnostic. A failed solve has no usable last iterate.

## Independence requirements for P4-T06-G4D

G4D is authorized to implement one bounded offline reproduction path. Its
minimum acceptance boundary is:

1. Read the exact R4 source/pack/manifest and P4-T08 fixture identities; do not
   use a host-local path or an unbound input.
2. Reconstruct the three case lookups from the explicit burnup vectors and
   frozen lookup contract.

   normalization in a separate scalar/checking path. It may not call

4. Use explicit node, edge, boundary, volume, coefficient, energy, unit, and
   target-power inputs. Preserve canonical ordering and deterministic
   arithmetic.
5. Record convergence, residual/error measures, iteration counts, invalid-data
   diagnostics, normalization diagnostics, and usable-state status. Non-finite,
   invalid, or nonconverged output fails closed.
6. Produce a path-free, hash-bound candidate artifact and manifest. The
   artifact must remain candidate evidence and must not add a runtime schema,

case mapping, if the current artifacts disagree, or if an independent
reference result is required but unavailable. A byte-identical or zero-
difference result against R5 would demonstrate bounded implementation
self-consistency only; it would not, by itself, approve physical accuracy or a
G4 tolerance.
