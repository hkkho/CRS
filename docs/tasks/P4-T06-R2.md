# P4-T06-R2 - Path-free DONJON5 case-admission audit

## Outcome

Status: BLOCKED

The authorized external DONJON5 package was identified and audited without
copying its private payload into the repository. The path-free provenance
record is sufficient to identify the Version5 source, pinned container and
program, staged-file hashes, input deck, run environment, and emitted source
diagnostics. It is not sufficient to admit the case as a solver-ready Core
comparison or golden baseline.

The remaining block is technical rather than legal: the selected HDF5 export
contains mixture-level two-group fields with source units such as `cm-1` and
`MeV/cm`, while the frozen P2-T02 contract requires explicit CANDU node
mapping, preassembled `T_g`/`B_g` conductances in `m^2`, `V_i` in `m^3`,
`E_f,i` in `J`, and mapped node-level observables. The inspected package does
not prove those bindings. Its embedded `ReactorType` is `PWR`, and its
assembly/lattice metadata is therefore not silently treated as CANDU runtime
or golden evidence.

Effectiveness: BLOCKED
