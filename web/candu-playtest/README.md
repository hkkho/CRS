# CRS browser client

The native DOM/SVG client displays the shared C# simulation through a dedicated Web Worker. The public entry point offers time-based play and the Custom physics sandbox.

- [Local setup](../../README.md#develop-and-verify)
- [Controls and scoring](../../docs/code-library/manual/index.md)
- [Worker, transactions and presentation](../../docs/code-library/index.md)
- [Pages build and verification](../../docs/maintenance/hosting.md)

`public/wasm` is generated by the root `tools/Build-BrowserWasm.ps1` script. Run `npm test` and `npm run build` here, or use the root `tools/Test-Browser.ps1` to include the shared bridge tests.
